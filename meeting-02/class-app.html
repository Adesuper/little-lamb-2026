📖 How to use this app (1 minute, read first)
  • Type in the name the class voted for last week — the app uses it on every page.
  • Tap Full Screen, then Let's Start! — 11 pages. Next with the green Next ➡ button or the → key.
  • Real games with right/wrong answers: Find the Lamb, Shepherd Thumbs, Count the Flock, Story in Order, Shepherd Quiz and the Magic Painting. Let a different child take each turn.
  • The app supports the Leader's Guide (pp. 37–42); the tents, the puppet, the paint and the baby bottle are still the lesson. The pages follow the lesson plan's order (the painting comes straight after the story).
